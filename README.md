# Война и мир (War and Peace in TXT)

Репозиторий содержит полный текст произведения Л. Н. Толстого «Война и мир», разбитый по томам, в исходных форматах PDF и сконвертированных текстовых файлах TXT, а также Python-скрипт для автоматической конвертации.

## Содержимое репозитория

* `Война и мир. Том 1.pdf` / `Война и мир. Том 1.txt` — Первый том
* `Война и мир. Том 2.pdf` / `Война и мир. Том 2.txt` — Второй том
* `Война и мир. Том 3.pdf` / `Война и мир. Том 3.txt` — Третий том
* `Война и мир. Том 4.pdf` / `Война и мир. Том 4.txt` — Четвертый том
* `pdf_to_txt.py` — Скрипт на Python для пакетного извлечения текста из PDF-файлов в TXT.

## Использование

### Скрипт конвертации
Для повторного извлечения текста или пакетной обработки запустите скрипт:

```bash
python pdf_to_txt.py
